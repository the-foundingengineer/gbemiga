# Oluwagbemiga — Designer Portfolio

A portfolio website built for Oluwagbemiga, a brand/web/motion designer, to showcase their client work. Static multi-page site with a home, about, and work index, plus individual case-study pages for six brand projects: Credensure, Daya, Hurupay, Ladder, Sorce, and Sweet Tooth. Built with a consistent grid-based layout system (fixed grid lines, full-bleed brand imagery, numbered SVG assets per project) so each case study reads as a distinct visual story while sharing one design language.

## Tech stack
Plain HTML/CSS/JS (no framework) — `index.html`, `about.html`, `work.html`, individual project pages, `styles.css`, `main.js`. Hosted from `https://github.com/the-foundingengineer/gbemiga`.

## Status
Live/shipped. Commit history (Aug 2026) shows active, iterative polish — grid alignment, contact section using SVG social icons only, padding/spacing fixes, motion project layout — consistent with a site that was refined through real client feedback rather than left as a first draft.
